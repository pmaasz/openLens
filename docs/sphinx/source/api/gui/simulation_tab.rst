Overview
--------

The ``SimulationTab`` provides the ray tracing simulation interface, allowing
users to run simulations and visualize ray paths through the lens. Its Focal
Plane controls set the model's ``image_plane_x_mm`` (or clear it for the
paraxial focus); the visualization marks a configured plane and reports the
RMS spot measured there.
